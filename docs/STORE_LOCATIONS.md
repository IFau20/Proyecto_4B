Locations and hours are provided with explicit official source URLs. The backend consults each contact page through `GET /api/stores` and marks `scheduleVerified` true only when the published address and timetable appear. If the website blocks a request, this flag stays false.

Published opening hours are reference information, not proof of being open today or on public holidays. Published online stock does not imply a branch has physical inventory. Coordinates approximate the street location. AI programming assistance: ChatGPT/OpenAI.
