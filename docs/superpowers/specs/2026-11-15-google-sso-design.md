# Google sign-in

User authorized Google integration after reviewing the Entra permissions blocker. Keep the existing Deno/React architecture and Microsoft compatibility. Use a provider selector and shared authorization-code/session machinery rather than a second account system or a hosted identity dependency. Google uses fixed official authorization, token and JWKS endpoints; no arbitrary provider URLs. Preserve state, nonce, PKCE and signature verification. Translate the provider button, supply an ignored local environment template, a PowerShell configurator and explicit real-account setup steps. Tests must exercise signed tokens and reject invalid claims. No Google registration credentials are available in this environment; never claim a real login before configuration and verification.
