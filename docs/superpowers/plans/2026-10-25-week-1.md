# Week 1 Computer Catalog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the smallest runnable React-to-Deno computer catalog as the first weekly increment of project 4B.

**Architecture:** Deno exposes computers from local JSON through a Handler and `GET /api/computers`. React fetches this endpoint and renders cards with the three agreed criteria, with Vite proxying requests in development.

**Tech Stack:** React, Vite, JavaScript/JSX, Deno, TypeScript, JSON, CSS, Vitest and Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-25-week-1-design.md`

## Global Constraints

- Three comparison criteria: RAM, GPU, processor.
- Example products/prices only, explicitly not live offers.
- Code identifiers in English, README in Spanish.
- Implement on `develop`, not `main`.

## Review Focus

- Unsupported methods should return 405, not a catalog.
- Unknown URLs should return 404.
- A broken API should show an error, not an empty catalog.
- An empty valid JSON array should show an empty state.
- Users should see the right specs/CLP prices for each computer on small screens.
