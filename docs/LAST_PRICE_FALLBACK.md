## Fuentes para equipos sin oferta vigente

Cuando ninguna tienda ofrece un precio actual o publicado para un SKU, el backend
puede consultar el historial público de ese **mismo código de fabricante** en SoloTodo
(últimos 365 días) y exhibir únicamente el último precio válido, claramente marcado
**«Último precio registrado»** con fecha. Es un dato histórico, **no** una oferta actual.
Este número no participa de comparaciones de tiendas, descuentos, stock ni carrusel,
y no se copia al registro de precios observados en vivo.

Los precios de referencia de comercios continúan teniendo prioridad sobre esta
alternativa histórica. Si no existe evidencia histórica válida tampoco se inventa un
valor. La red o SoloTodo pueden no estar disponibles.
